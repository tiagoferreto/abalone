# Abalone

Jogo de estratégia para dois jogadores, feito em uma única página HTML.

Jogue em: https://tiagoferreto.github.io/abalone

## Regras

- As escuras começam. Cada jogada move de 1 a 3 esferas da sua cor, uma casa só.
- As esferas precisam estar alinhadas (as diagonais valem).
- Em fila, a esfera da frente empurra as outras. De lado, o grupo desliza para casas vazias.
- Sumito: só dá para empurrar o adversário com mais esferas do que ele (2 contra 1, 3 contra 1, 3 contra 2).
- Vence quem derrubar 6 esferas do adversário.

## Modos

- 2 jogadores
- Contra o computador: fácil, médio e difícil

## Rodar localmente

Abra o arquivo `index.html` no navegador. Não há dependências.
